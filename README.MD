# Restaurant Tipping Analytics Dashboard

Interactive Streamlit application built for statistical analysis, parametric/non-parametric hypothesis testing, and OLS regression diagnostics on the Seaborn tips dataset.

## How to Run Locally
1. Clone repository: `git clone https://github.com/aarushi-202618017/Stats_Lab_04_Tipping_Dashboard`
2. Create virtual environment: `python -m venv venv`
3. Activate environment: `venv\Scripts\activate` (Windows) or `source venv/bin/activate` (Mac/Linux)
4. Install dependencies: `pip install -r requirements.txt`
5. Run dashboard: `streamlit run app.py`
